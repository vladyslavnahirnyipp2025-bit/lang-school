# «Репліка» — школа іноземних мов

**Сайт:** https://lang-school-pi.vercel.app/

Навчальний лендинг: семантичний HTML, Tailwind CSS 3 (CLI), JavaScript без фреймворків.
Школа вигадана, ціни й відгуки демонстраційні, форма нікуди не надсилає дані.

## Що є на сторінці

- живий діалог чотирма мовами з перекладом по натисканню;
- рухома стрічка привітань, плаваючі слова, поява блоків під час прокручування;
- картки мов, що перевертаються;
- шлях A1–C1 із лінією, яка заповнюється під час прокручування;
- тест рівня англійської з 9 запитань;
- калькулятор вартості курсу;
- слайдер відгуків (Swiper 11.1.14) і акордеон із запитаннями;
- форма запису на пробний урок із перевіркою полів.

Анімації вимикаються, якщо в системі ввімкнено «зменшення руху».

## Структура

| Файл | За що відповідає |
|---|---|
| `index.html` | розмітка сторінки |
| `tailwind.config.js` | кольори, шрифти, анімації |
| `src/input.css` | компоненти; з нього збирається `assets/css/styles.css` |
| `assets/js/logic.js` | чисті функції: ціна, рівень, перевірка форми |
| `assets/js/main.js` | меню, прокручування, картки, FAQ, слайдер |
| `assets/js/hero.js` | живий діалог |
| `assets/js/quiz.js` | тест рівня |
| `assets/js/forms.js` | калькулятор і форма |
| `tests/logic.test.js` | тести |

## Команди

```powershell
npm install
```

```powershell
npm run build:css
```

```powershell
npm test
```

Після збірки відкрийте `index.html` у браузері. Шрифти та Swiper завантажуються з інтернету.
